# Données

Ce dossier est prévu pour contenir localement le fichier de données utilisé dans le projet.

## Fichier attendu

```text
Building_Energy.csv
```

Ce fichier n'est pas versionné dans GitHub.

## Pourquoi le fichier CSV n'est pas inclus ?

Le fichier de données peut être volumineux et ne doit pas nécessairement être stocké directement dans le dépôt GitHub.

Le dépôt contient uniquement le code, les notebooks, la logique d'API et les fichiers nécessaires à la reproduction du projet.

## Utilisation

Avant d'exécuter les notebooks, placer le fichier CSV dans ce dossier :

```text
data/Building_Energy.csv
```

Les notebooks peuvent ensuite charger les données depuis ce chemin local.
